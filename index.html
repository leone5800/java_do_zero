Tópicos

01

O que é Java?

Java é uma linguagem de programação orientada a objetos, criada pela Sun Microsystems (hoje pertence à Oracle). Ela é usada em sistemas bancários, aplicativos Android, sistemas de empresas e muito mais.

A ideia principal: "escreva uma vez, rode em qualquer lugar"

O código Java não é executado direto pelo computador. Ele passa por duas etapas:

  • Compilação: o código-fonte (.java) é transformado em bytecode (.class) pelo JDK.
  • Execução: a JVM (Java Virtual Machine) lê esse bytecode e executa no sistema operacional, seja Windows, Linux ou Mac.
terminal 
javac Main.java   // gera Main.class (bytecode)
java Main         // a JVM executa o bytecode
JDK, JRE e JVM — o JDK é o kit completo para desenvolver (inclui compilador). O JRE é o ambiente para só executar programas. A JVM é a "máquina" dentro do JRE que realmente interpreta o bytecode.

02

Estrutura de um programa Java

Todo programa Java começa com uma classe, e toda execução começa pelo método main. É esse método que a JVM procura primeiro.

Main.java 
public class Main {
    public static void main(String[] args) {
        System.out.println("Ola, mundo!");
    }
}
saída 
Ola, mundo!

Explicando cada peça

  • public class Main — declara uma classe pública chamada Main. O nome do arquivo precisa ser igual ao nome da classe.
  • public static void main(String[] args) — o ponto de entrada do programa.
  • System.out.println(...) — imprime um texto no console, com quebra de linha no final.
  • ; — cada instrução em Java termina com ponto e vírgula.

03

Variáveis e tipos de dados

Uma variável é um espaço na memória com um nome, um tipo e um valor. Em Java, o tipo precisa ser declarado antes de usar a variável — isso chama-se tipagem estática.

Variaveis.java 
int idade = 20;
double altura = 1.75;
char inicial = 'M';
boolean aprovado = true;
String nome = "Maria";

Tipos primitivos mais usados

  • int — números inteiros (sem casas decimais).
  • double — números com casas decimais.
  • boolean — apenas true ou false.
  • char — um único caractere, entre aspas simples.
  • String — texto (não é primitivo, é uma classe, mas usamos como se fosse).
Diferença importante: aspas simples 'A' são char; aspas duplas "A" são String.

04

Operadores

Operadores combinam valores e variáveis para produzir um resultado. Os principais grupos são aritméticos, relacionais e lógicos.

Operadores.java 
int x = 10;
int y = 3;

System.out.println(x + y);  // soma
System.out.println(x % y);  // resto da divisao
System.out.println(x > y);  // comparacao
System.out.println(x > 0 && y > 0); // "e" logico

Grupos principais

  • Aritméticos: + - * / % (o % é o resto da divisão).
  • Relacionais: == != > < >= <= — sempre resultam em true ou false.
  • Lógicos: && (e), || (ou), ! (negação).

05

Estruturas condicionais

Condicionais permitem que o programa tome decisões, executando um bloco de código diferente dependendo de uma condição.

Condicional.java 
int idade = 20;

if (idade >= 18) {
    System.out.println("Maior de idade");
} else {
    System.out.println("Menor de idade");
}

switch: quando há muitas opções fixas

Switch.java 
int dia = 3;

switch (dia) {
    case 1: System.out.println("Segunda"); break;
    case 2: System.out.println("Terca"); break;
    case 3: System.out.println("Quarta"); break;
    default: System.out.println("Dia invalido");
}

06

Laços de repetição

Laços (ou "loops") repetem um bloco de código enquanto uma condição for verdadeira. Evitam que a gente escreva a mesma linha várias vezes.

For.java 
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}

while e do-while

  • for — ideal quando já sabemos quantas vezes repetir.
  • while — repete enquanto a condição for verdadeira, testada antes.
  • do-while — igual ao while, mas testa a condição depois, então o bloco roda pelo menos uma vez.
DoWhile.java 
int senha;
do {
    senha = 1234; // simulacao de leitura
} while (senha != 1234);

07

Vetores (arrays)

Um array guarda várias posições do mesmo tipo, acessadas por um índice que começa em zero.

Vetor.java 
int[] notas = {8, 9, 7, 10};

System.out.println(notas[0]); // primeira posicao
System.out.println(notas.length); // tamanho do vetor

for (int i = 0; i < notas.length; i++) {
    System.out.println(notas[i]);
}
O índice sempre começa em 0. Em um array de 4 posições, os índices válidos vão de 0 a 3.

08

Métodos

Um método é um bloco de código com nome, que pode receber parâmetros e devolver um resultado. Serve para organizar e reaproveitar código.

Metodos.java 
public static int somar(int a, int b) {
    return a + b;
}

public static void main(String[] args) {
    int resultado = somar(2, 3);
    System.out.println(resultado);
}

Peças de um método

  • Tipo de retorno: int, void, String... define o que o método devolve.
  • Parâmetros: valores que o método recebe para trabalhar.
  • return: devolve o resultado e encerra o método.

09

Classes e objetos

Java é uma linguagem orientada a objetos. Uma classe é um molde que descreve atributos (dados) e métodos (comportamentos). Um objeto é uma instância concreta criada a partir desse molde.

Carro.java 
public class Carro {
    String modelo;
    int ano;

    void buzinar() {
        System.out.println("Fom fom!");
    }
}

Criando um objeto a partir da classe

Main.java 
Carro meuCarro = new Carro();
meuCarro.modelo = "Fusca";
meuCarro.ano = 1978;
meuCarro.buzinar();
  • Atributos (modelo, ano) — guardam o estado do objeto.
  • Métodos (buzinar) — definem o comportamento do objeto.
  • new — palavra-chave que cria uma instância da classe na memória.
